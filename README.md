# 🎮 たのしいタイピングゲーム

7歳のお子さんが楽しくローマ字を学べるタイピングゲームです！

## 🌐 ゲームで遊ぶ

**👉 [ここをクリックして遊ぶ！](https://belieeve.github.io/typinggame/)**

ブラウザで開くだけで、すぐに遊べます！
- Windows（ウィンドウズ）でもMac（マック）でも使えます
- インストール不要
- インターネットがあればどこでも遊べます

---

## 🎯 このゲームの特徴

### 💡 ローマ字を知らなくても大丈夫！

お子さんが「ローマ字がわからない！」「文字を打ちたくない！」と思っても大丈夫です。

#### こんな工夫をしています：

✅ **光るキーボード**
押すべきキーがキラキラ光ります！

✅ **やさしい説明**
「k をおして、つぎに a をおしてね」のように、わかりやすく教えてくれます

✅ **順番がわかる**
K → A のように、押す順番を矢印で表示します

✅ **スキップできる**
難しい問題は「むずかしい！つぎへ」ボタンでスキップOK！

✅ **優しいメッセージ**
間違えても「だいじょうぶ！ゆっくりでいいよ！」と励ましてくれます

✅ **たくさん褒めてくれる**
正解すると「すごい！」「やったね！」「てんさい！」と褒めてくれます

## 📚 学べる内容

### レベル1〜18まで、段階的に学習！

| レベル | 学ぶ内容 | 例 |
|--------|----------|-----|
| 1 | あいうえお（母音） | あ → `a` |
| 2〜10 | か行〜わ行 | か → `ka`、さ → `sa` |
| 11〜15 | 濁音・半濁音 | が → `ga`、ぱ → `pa` |
| 16〜18 | 拗音（小さい「ゃゅょ」） | きゃ → `kya`、しゅ → `syu` |

## 🎮 遊び方

### 1️⃣ スタートボタンを押す
「スタート！」ボタンをクリックしてゲーム開始！

### 2️⃣ 画面を見る
- **大きなひらがな**が表示されます（例：「か」）
- その下に**ローマ字**が表示されます（例：「ka」）
- **光っているキー**を見つけます

### 3️⃣ キーボードを押す
- 光っているキーを順番に押します
- 正解すると緑色に変わります！

### 4️⃣ レベルアップ！
- 5問正解するとレベルアップ！
- だんだん難しくなっていきます

### 💡 むずかしいときは…
「むずかしい！つぎへ」ボタンを押して、次の問題に進めます！

## 👨‍👩‍👧 保護者の方へ

### このゲームを作った理由

お子さんが**「ローマ字がわからないから、キーボードを打ちたくない」**という壁を乗り越えられるように作りました。

### 学習のポイント

- **無理強いしない**: スキップ機能で、できる問題から楽しめます
- **視覚的に学ぶ**: キーボードの図と矢印で、直感的にわかります
- **褒めて伸ばす**: 正解すると必ず褒めて、モチベーションアップ
- **段階的**: 簡単な「あいうえお」から始めて、徐々に難しく

### おすすめの使い方

1. **1日5〜10分程度**から始める
2. **無理に全部クリアしようとしない**
3. **一緒に遊んで褒める**（「すごいね！」「上手だね！」）
4. **できたレベルを記録する**（達成感を味わえます）
